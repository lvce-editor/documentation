# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

VitePress, extending its standard theme. An npm-workspace monorepo. Static deployment to GitHub Pages.

## Users

People learning to use LVCE Editor and developers building extensions. Readers arrive with a task or a question.

## Product Purpose

Help readers finish everyday editing tasks and create working extensions without guessing at missing steps.

## Capabilities and Constraints

Document the latest released editor. Reuse pinned examples from the separate extension-samples repository. Show actual source and initial preview DOM at build time, then activate the LVCE workers on interaction. Prioritize complete tutorials and important API references; browser LSP and exhaustive API coverage can follow.

## Brand Commitments

Original, useful, minimal design built on standard documentation conventions. It must not feel like an untouched theme or a generic promotional page. Use direct, concrete writing. The homepage prioritizes finding tasks while briefly introducing and demonstrating LVCE.

## Evidence on Hand

The agreed plan is in lvce-editor-planning/v1/documentation/README.md. The blog already uses VitePress. extension-samples supplies real editable examples; about-view supplies a GitHub Pages deployment precedent.

## Product Principles

- A complete task is more useful than an unfinished catalog.
- Show working code and results together.
- Reading does not start the editor runtime.
- Keep the examples and their explanations aligned.

## Accessibility & Inclusion

Keyboard access, readable typography, light and dark themes, and usable narrow layouts.
