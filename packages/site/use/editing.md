# Edit and navigate

Open a folder and a text file before trying these actions. The Explorer lists your files, tabs identify open documents, and the editor is where you make changes.

## Move between files

Click a file in the Explorer to open it. Use **Ctrl+P** on Windows/Linux or **Command+P** on macOS to search for a file by name. Type part of its name, select a result, and press Enter. Press Escape to dismiss the picker.

Click a tab to return to an open file. Close a tab using its close button. Save changes you want to keep before closing a document.

## Select and change text

Drag over text to select it. Hold Shift while pressing an arrow key to extend a selection. Typing replaces the selected text. Use the platform's normal copy, cut, paste, and undo shortcuts.

| Action             | Windows / Linux | macOS             |
| ------------------ | --------------- | ----------------- |
| Save               | Ctrl+S          | Command+S         |
| Undo               | Ctrl+Z          | Command+Z         |
| Copy / cut / paste | Ctrl+C / X / V  | Command+C / X / V |
| Find in this file  | Ctrl+F          | Command+F         |
| Go to a file       | Ctrl+P          | Command+P         |

These are default shortcuts. Your [keybindings](./settings#change-a-keybinding) may differ.

## Jump to a location

Use the command palette to search for **Go to Line**, then enter a line number. Language extensions may add symbol navigation, definitions, completions, and hover information; their availability depends on the language and installed extensions.

If a shortcut does not perform the expected action, focus the editor first and check your keybindings. Continue with [find and replace](./search).
