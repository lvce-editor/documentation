# Install extensions

Extensions add language support and other editor features. Choose an extension for a task you actually need, and read its requirements before installing it.

## Find and install an extension

1. Open the **Extensions** view.
2. Search for the extension or language name.
3. Open the result to inspect its description and requirements.
4. Choose **Install**. Follow any reload prompt shown by the editor.
5. Open a matching file or run one of the extension's commands to verify that it works.

A language extension may need a separately installed executable or runtime. The extension's own instructions are the source of those prerequisites.

## Disable or remove an extension

Open its details from the installed extensions list. Disable it when you want to test the editor without its behavior, or uninstall it when you no longer need it. Follow any reload prompt.

If an extension fails, check its platform requirements, the file's language, and whether the extension is enabled. The browser editor cannot run every desktop extension; native processes and filesystem access have different constraints.

## Develop your own

Start with [Hello World](../extensions/hello-world). You can edit and run it in the guide, then use a local copy without publishing or installing it permanently.
