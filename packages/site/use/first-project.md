# Open your first project

You need an installed copy of [LVCE](./installation) and a folder you can edit. A project can be any folder; it does not need a special project file.

## Open a folder

1. Launch LVCE.
2. Open the command palette with **F1**. On keyboards with media keys, you may need **Fn+F1**.
3. Search for **Open Folder**, select the command, and choose your project folder.
4. Expand a directory in the Explorer and open a text file.

The Explorer should now list the files in that folder, with the selected file open in a tab.

On installations with the `lvce` command available, you can also open a folder from a terminal:

```sh
lvce ./my-project
```

## Make and save an edit

Type a small change in the file. Save with **Ctrl+S** on Windows/Linux or **Command+S** on macOS. Reopen the file to confirm the change is on disk.

For a fresh practice file, use the Explorer's **New File** action, name the file `notes.txt`, type a sentence, and save it.

## Find an action

Use **F1** whenever you know what you want to do but do not know its shortcut. The palette searches available commands, including commands contributed by installed extensions.
