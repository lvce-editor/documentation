# Use LVCE

Start with a folder of your own files. Learn the small set of actions you will use every day, then adjust the editor to suit your work.

## Your first session

1. [Install LVCE](./installation) for your computer.
2. [Open a project](./first-project) and save your first edit.
3. [Navigate your code](./editing) using the Explorer, tabs, and quick file navigation.

## Everyday tasks

- [Find and replace](./search) in one file or across a project.
- [Change settings and keybindings](./settings).
- [Install extensions](./extensions) for the languages and tools you use.

You do not need to write an extension to use LVCE. When you want to add a feature of your own, start with [Build extensions](../extensions/).
