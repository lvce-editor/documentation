# Find and replace

Use file search when you know which document contains the text. Use project search when you need to find its location.

## Find in the current file

1. Focus the editor and press **Ctrl+F** or **Command+F**.
2. Enter a word that appears in the document.
3. Use the next and previous match controls to move between results.
4. Press Escape to return to editing.

Matches should be highlighted in the open document. Enable case sensitivity, whole-word matching, or regular expressions only when your search needs them.

## Replace in the current file

Expand the find widget's replacement controls. Enter the replacement text and replace one match first. Check the result before replacing all matches. Undo restores an unwanted edit.

## Search a project

Open the **Search** view in the sidebar. Enter your query and run the search. Expand a result group and select a match to open its file at that location.

Use include/exclude patterns when you need to narrow the results. If a known match is absent, check the active folder, patterns, case sensitivity, and regular-expression setting.

## Replace across files

Use the Search view's replacement controls. Inspect the matching files and changes before applying a project-wide replacement. Save the changed files when you are satisfied with the result.

For a first test, search a small practice folder with a known repeated word. You should be able to find every occurrence and open each result.
